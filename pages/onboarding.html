Welcome to Summaryse

Summarize any text on the web instantly using local AI inference.

✓
Select text on any webpage
✓
Right-click → "Summarize with Summaryse"
✓
Choose a style: Bullets, TL;DR, Paragraph, or Takeaways
✓
Keyboard shortcut: Cmd+Shift+S (Mac) or Ctrl+Shift+S (Windows/Linux)

All summarization is done locally on your device using WebLLM. No data is sent to external servers.
