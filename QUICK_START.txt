THREE-STEP INSTALLATION
─────────────────────────────────────────────────────────────────────────────

1. Open:     chrome://extensions/
2. Toggle:   Developer mode (top-right)
3. Click:    Load unpacked → Select this folder

✅ Done! The extension loads instantly.


FIRST USE (2-3 minutes)
─────────────────────────────────────────────────────────────────────────────

1. Select any text on any webpage
   → Blue "Summarize" button appears near selection

2. Click the button
   → Popup window opens

3. Click "Summarize" in popup
   → Shows "Downloading AI model..." (first time only)
   → Model downloads (~220MB) - takes 1-2 minutes
   → Summarization starts

4. Wait for summary
   → Summary streams in token-by-token
   → Takes 1-5 seconds for typical text

5. Copy or create new summary
   → Click "Copy" to copy to clipboard
   → Click "New Summary" for different text


SUBSEQUENT USES (instant)
─────────────────────────────────────────────────────────────────────────────

1. Select text (as before)
2. Click button (as before)
3. Click "Summarize" (as before)
4. Summary appears in 1-2 seconds ✓

KEY TECHNICAL DECISIONS
─────────────────────────────────────────────────────────────────────────────

1. WebLLM (not custom WASM)
   ✓ Mature, well-maintained
   ✓ Automatic GPU optimization
   ✓ Easy model swapping

2. Service Worker (not content script)
   ✓ Better for expensive computation
   ✓ Singleton pattern for reuse
   ✓ Proper error handling

3. Streaming tokens (not batch)
   ✓ Feels faster to user
   ✓ Progressive UI updates
   ✓ Better perceived performance

4. IndexedDB caching
   ✓ Automatic persistence
   ✓ Large file support
   ✓ No re-download on update

5. Simple chunking (not semantic)
   ✓ Fast, deterministic
   ✓ Good enough for POC
   ✓ Easy to understand/modify


CUSTOMIZATION
─────────────────────────────────────────────────────────────────────────────

Change the Summarization Prompt:
  → Edit background.js, lines 130-150
  → Modify systemPrompt or userPrompt

Use a Different AI Model:
  → Edit background.js, line 11
  → Change: const MODEL_ID = "NewModelID"
  → Available models: https://huggingface.co/webllm

Adjust Streaming Behavior:
  → Edit popup.js, updateSummaryDisplay() method
  → Modify how tokens are rendered

Change UI Colors:
  → Edit styles.css
  → Primary color is #4F46E5 (indigo)
  → Easy find-and-replace


TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

❌ Extension doesn't appear
   → Reload webpage (Cmd+R / Ctrl+R)
   → Check chrome://extensions/ (should be listed)

❌ Floating button not showing
   → Select 5+ character text
   → Wait 200ms after selection
   → Check different website (some block extensions)

❌ Model download fails
   → Check internet connection
   → Ensure 300MB+ free space
   → Check chrome://gpu for WebGPU support

❌ Summarization is slow
   → First run is slow (model loading)
   → Subsequent runs should be 1-2 seconds
   → Longer texts take longer (1 second per 500 chars)

❌ "WebGPU not available"
   → Check chrome://gpu (should show WebGPU)
   → Update Chrome to latest version
   → Update GPU drivers

See SETUP.md for more troubleshooting help.

DEBUG MODE
─────────────────────────────────────────────────────────────────────────────

View Extension Logs:
  1. Right-click extension icon
  2. Select "Inspect popup"
  3. Look for console messages
  4. Errors appear in red

View Service Worker Logs:
  1. Go to chrome://extensions/
  2. Find Summaryse
  3. Click "Service worker" link
  4. View console output

Check Model Cache:
  1. Press F12 (DevTools)
  2. Application → Storage → IndexedDB
  3. Look for WebLLM entries
  4. Should show ~220MB cached


UPDATING THE EXTENSION
─────────────────────────────────────────────────────────────────────────────

Chrome automatically checks for updates.

To manually reload after editing:
  1. Edit file (e.g., background.js)
  2. Save file
  3. Go to chrome://extensions/
  4. Click the refresh icon for Summaryse
  5. Changes take effect immediately

To clear model cache:
  1. Settings → Privacy → Clear browsing data
  2. Select "IndexedDB"
  3. Clear data
  4. Next use will re-download model
